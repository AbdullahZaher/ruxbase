# Website contributor instructions

Inherit the root AGENTS.md and read the current brand guidelines and tokens before visual changes. Public Markdown comes only from docs/public/manifest.json; generated content, output, performance and browser evidence are not hand-edited. Use the existing pinned npm site lock; run npm run test:foundation, npm run test:ai, npm run build, node scripts/check-build.mjs, node scripts/check-ai.mjs, npm run test:retrieval and the applicable browser/performance checks. Do not advertise stable releases without an approved tag. The public static profile excludes the optional unreviewed Scalar viewer; do not publish the local preview. Preserve exact source identity and failure gates. Deploy only through the reviewed main-only workflow after exact-main CI and authorized Pages settings.
